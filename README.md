# 哪吒之魔童降世 · 电影宣传站

一个使用 HTML、CSS 和 JavaScript 编写的《哪吒之魔童降世》静态电影宣传网站。

## 预览

GitHub Pages: https://arrver.github.io/nezha-movie-site/

## 功能

- 固定顶部导航与移动端菜单
- 国风电影海报 Hero 区域
- 电影简介、预告片与剧照网格
- 主要角色介绍
- 精彩剧情时间线
- 在线留言表单（前端 `alert` 演示）
- 登录 / 注册弹窗
- 响应式布局与无障碍焦点样式

## 说明

页面为纯静态单文件项目，图片和视频均使用占位链接。直接打开 `index.html` 即可运行。
